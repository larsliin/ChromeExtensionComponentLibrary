# Component overview

This quick catalog lets you preview what's included without cloning the repository. Follow a component link for its full documentation and examples.

## Actions

- [BaseButton](docs/components/base-button.md) — Primary, secondary, tool, and bare buttons.
- [BaseCopyButton](docs/components/base-copy-button.md) — Copies text and provides temporary success feedback.
- [BaseIconButton](docs/components/base-icon-button.md) — Accessible icon-only button for toolbars.
- [BaseHeroButton](docs/components/base-hero-button.md) — Large call-to-action button with an icon, title, and caption.

## Form fields

- [BaseSelect](docs/components/base-select.md) — Native select field.
- [BaseMenuSelect](docs/components/base-menu-select.md) — Compact custom dropdown with a floating options panel.
- [BaseCheckbox](docs/components/base-checkbox.md) — Checkbox with an optional label.
- [BaseNumberInput](docs/components/base-number-input.md) — Number input field.
- [BaseRangeInput](docs/components/base-range-input.md) — Range slider.
- [BaseCodeEditor](docs/components/base-code-editor.md) — CodeMirror editor; CodeMirror is an optional peer dependency.

## Feedback

- [BaseAlert](docs/components/base-alert.md) — Error, warning, and information messages.
- [BaseLoadingBar](docs/components/base-loading-bar.md) — Indeterminate progress indicator.

For detailed usage, props, and examples, see the [component documentation](docs/components/index.md).
